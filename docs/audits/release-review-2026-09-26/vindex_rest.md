# Pre-release review — larql-vindex (excluding src/format/vindex3/), larql-vindex-spec, vindex-cli

Scope: 345 .rs files / ~92k lines in `crates/larql-vindex/src` outside `format/vindex3/`, plus `tests/`, `examples/`, `benches/`; `crates/larql-vindex-spec` (4 files); `crates/vindex-cli` (4 src + 2 tests). Read-only review, working tree on `vindex3/qkv-attention-bias` (uncommitted edits present in `config/model.rs`, `format/weights/load/arch.rs` — reviewed as-is).

Paths below are relative to `crates/larql-vindex/src/` unless prefixed with a crate name.

Severity: **P0** = release blocker (memory safety / data-corruption on a normal path), **P1** = fix before release, **P2** = cleanup / follow-up.
